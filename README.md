# Salary Prediction - EDA

This is a second-year exploratory data analysis project that I did on the Salary Data dataset.

I created visualisations in R to answer three questions I came up with for the project:
1. How does salary vary with years of experience or age?
2. Which education level group shows the highest average salary?
3. Are there visible differences in salary between genders?
